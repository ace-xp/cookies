## 零、先接受一个事实：现在只有一条线能录

我把四个业务系统在本地挨个点过了：

| 系统 | 本地现状 | 能不能录 |

| 创意创作 | 零个创意任务，全是空态 | 不录 |

**所以这条视频的定位是：讲清楚「素材洞察」这一个系统，顺带交代它在平台里的位置。**
不要试图讲完整平台——录到一半全是空页面，比不录还伤。

## 一、开录前 10 分钟

### 1. 环境自检（三样都要活着）

```bash
docker ps --format '{{.Names}}\t{{.Status}}'
```

要看到 `deployments-mysql-1` 和 `cookies-tika-1` 都是 Up。

```bash
curl -s http://127.0.0.1:8080/healthz
```

要返回 `{"status":"ok"}`。前端在 5173，浏览器能打开就行。

### 1.5 铺数据（两个脚本，按顺序跑）

```bash
bash scripts/seed-insight-showcase.sh
```

```bash
bash scripts/seed-insight-prelaunch-demo.sh
```

两个都可以重复跑，不会翻倍。第二个跑完会打印投前那一屏的最终数字，
和第三节段 5 里写的对上就说明铺好了。

### 2. 屏幕收拾干净

- 浏览器**新开一个干净窗口**，只留一个标签页
- 关掉书签栏（`Ctrl+Shift+B`）
- 缩放设成 **100%**，窗口最大化；录 1920×1080
- 关掉一切会弹通知的东西（微信、邮件、系统更新）

### 3. 定妆：先手动走一遍全流程

**不要跳过这一步。** 按下面第三节的路径空走一遍，确认每一屏都出得来东西。走完把项目切回洞察的「分析 · 指标总览」，从那里开始录。

### 4. 有几个地方会出戏，心里先有数

- 页脚永远显示「阶段：无法计算 / 进度：无法计算」——**别把鼠标停在页脚**，也别念它
- 智能投放页顶部有一条黄色的「Mock 环境」提示——如果要录那一屏，**主动念出来**，别让人自己发现
- 「投前」入口在服务器上还没有（线上是旧版本），**这条视频只能在本地录**

## 二、整体结构（建议 8~10 分钟，分 6 段录）

**分段录，不要一镜到底。** 每段单独一个文件，剪的时候好接，念错了只重录那一段。

| 段 | 内容 | 时长 | 屏幕 |
|---|---|---|---|
| 0 | 平台是干什么的 | 40 秒 | Home |
| 1 | 数据怎么进来的 | 1 分 | 洞察 · 设置/数据接入 |
| 2 | 分析：六个视图 | 3 分 | 洞察 · 分析 |
| 3 | 复盘：人记的和系统补的 | 1.5 分 | 洞察 · 复盘 |
| 4 | 经验：分量不一样 | 1.5 分 | 洞察 · 经验 |
| 5 | 投前：下一轮怎么用 | 1 分 | 洞察 · 投前 |

口播稿见第四节。**照着念，但别背**——念错一句就停下来重录那一句，剪掉就行。

## 三、逐段走位（精确到点哪里）

### 段 0 · Home（40 秒）

1. 打开 `http://localhost:5173`，停在 Home
2. 鼠标**慢慢划过**顶部五个系统名：Home / 需求与策略 / 创意创作 / 素材洞察 / 智能投放
3. 划到「素材洞察」时点进去

⚠️ 别点开需求与策略和创意创作，里面是空的。

### 段 1 · 数据接入（1 分）

1. 左侧点「**设置**」→ 找到数据接入那一组（或从分析页顶部黄条里的链接进）
2. 顶部四个标签依次点：`数据源` → `导入任务` → `字段映射` → `素材映射`
3. 停在「**素材映射**」，这一屏最能说明问题
4. 点最上面那条 **待匹配** 的对象，右栏展开「没认领的后果」那段黄字

**这一屏的重点**：报表里的广告 ID 系统不认识，但**不能因为不认识就扔掉**，它的钱是真花的。

### 段 2 · 分析（3 分，全片核心）

1. 左侧点「**分析**」，默认停在 `指标总览`，窗口默认「近 30 天」
2. 先指顶部黄条：`有 1 个平台对象还没认领，¥4,607.82 花费计入了总盘但算不到任何素材头上`
3. 再指四个数字：花费 ¥71,881.90 / 曝光 990,340 / 点击率 3.01% / 转化成本 ¥43.25
4. 指「👁 只是观察」那个徽标，念右边那句「结论只能是方向性的，且不应据此自动优化」
5. 依次点标签：`趋势` → `疲劳` → `异常` → `驱动因素`

每个视图停 20~30 秒，念对应的口播。**每个视图都要指一下那句判定**（explained / observed），这是这个产品最值钱的地方。

6. 在「驱动因素」那一屏，鼠标停在右侧「**记一笔**」按钮上——**不要点**，只说明它是干什么的（真点了会往复盘草稿里塞一条，跟已有的那份已确认复盘对不上）

### 段 3 · 复盘（1.5 分）

1. 左侧点「**复盘**」
2. 展开那份已确认的报告，共 11 条发现
3. 指出两组的区别：「**我记的**」在前（3 条），「**系统补的**」在后

### 段 4 · 经验（1.5 分）

1. 左侧点「**经验**」，共 8 条（跑完两个 seed 之后）
2. 找那条 `统计观察` + `已确认` + 「样本充分」的，念一遍
3. 再找那条 `假设` + `待确认` + 「方向性」的（`同一版素材连续投放到第三周…`），对比着讲
4. 展开第一条的证据链，指「凭什么」
5. 勾一下「**连只是观察的也看**」——这里能看到全部，投前那一屏看不到，两屏的定位不一样

**这一段的重点**：类型和置信度是**人打的**，不是模型打的。

### 段 5 · 投前（1.5 分）

> 这一屏的数据由 `scripts/seed-insight-prelaunch-demo.sh` 铺出来，7 条结论、6 个特征。
> 录之前先跑一遍（可重复执行，跑第二遍只会打印「已存在」）。

1. 左侧点「**投前**」，默认停在「结论」
2. 顶部那行：`按（没设条件）筛出 7 条。另有 6 个反复有效的内容特征，在「历史模式」里`
3. 挑一条念完整：`视频号的数字人口播控制在 22 秒以内时…`，指它的「适用：Nova 家清 · 视频号 · 数字人口播 · 新品拉新」——**重点是「适用」这一行**，没有它，一条结论就是一句正确的废话
4. 指那条黄字：`这些结论来自 小红书、抖音、视频号 多个渠道`，说明系统为什么不让人横着比
5. **渠道选「抖音」**——列表从 7 条收到 4 条，同时冒出第二条黄字 `另有 1 条没写适用范围，被挡在外面`。这是全片最好演的一处：被挡掉的东西**报了数**，没有静默丢
6. 点「清空条件」，切到「**历史模式**」标签：`hook_type` 被 3 条互相独立的结论提到，排在最上面。说明这一屏的问法和上一屏是反的——上一屏问「这次能用什么」，这一屏问「有什么一直有效」
7. 切回「结论」，鼠标划过「**凭什么**」和「**用进 Brief**」——「凭什么」可以点开看证据链，「用进 Brief」**别点**（会真的写一条引用记录）

⚠️ 「历史模式」里的特征名现在显示的是英文键（`hook_type` / `subtitle_density`），**别停在上面逐个念**，
说「这些是素材上的内容特征」带过去就行。

⚠️ showcase 里那条「👁 只是观察」的经验**不会**出现在这一屏——这是设计如此，不是漏了。
如果要讲，切到「经验」入口去讲，别在这里找。

结尾停在这一屏。

## 四、口播稿

见对话里给过的那一版（分析 → 复盘 → 经验 → 投前）。三条硬原则：

1. **每一屏都要说出那句判定**——「能归因」还是「只是观察」，这是差异点
2. **主动说系统不知道什么**——断档那天、没认领那条，这些是加分项不是减分项
3. **别说「智能」「AI 自动」**——这个产品的卖点恰恰是「模型不替人下结论」
