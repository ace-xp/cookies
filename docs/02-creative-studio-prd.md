# 广告创意创作 PRD

| 属性 | 内容 |
| --- | --- |
| 模块 | 广告创意创作 |
| 文档版本 | v1.0 |
| 文档状态 | 草案 |
| 目标版本 | M1 / MVP |
| 核心形态 | 图文创作 + 视频创作 |
| 重点渠道 | 图文：小红书、公众号；视频：抖音、快手 |
| 视频类型 | 品牌广告制作、效果广告制作；效果广告首期含 4 种生成类型 |
| 视频通用工具 | 素材剪辑 |

## 1. 产品定义

本模块把已批准策略转化为适配具体渠道的创意内容。创意不是一个泛化的“文案 + 图片”对象，而是两条差异明显的生产线：

1. **图文创意**：面向小红书、公众号等内容渠道，交付可发布的图文内容包。
2. **视频创意**：面向抖音、快手等视频渠道，并进一步区分品牌广告制作和效果广告制作。
3. **素材剪辑**：面向两类视频广告和用户存量素材，提供独立的多轨时间线、字幕、音频、比例适配、版本和导出工作区。

不同形态共享品牌知识、素材经验、版本、评审与合规能力，但拥有不同的内容结构、生成 Skills、质量标准和效果指标。

## 2. 产品目标

1. 从策略快速生成符合小红书、公众号表达习惯的完整图文内容，而非只生成零散文案。
2. 为抖音、快手分别生成渠道适配的视频方案、脚本、分镜、素材组合和成片草稿。
3. 品牌广告以 Brief 解析、剧本、资产生成、广告生成和剪辑为固定生产主线；效果广告以视频爆款复刻、视频前贴、AI 数字人、AI 广告生成四种明确功能完成转化创意生产。
4. 将品牌规则、素材经验和历史效果纳入创作上下文，减少同质化与重复踩坑。
5. 支持多方向探索、受控变体、人审、合规与效果回流。
6. 支持将上传素材、AI 生成镜头和授权历史素材进行非破坏性剪辑，形成可继续评审与投放的 CreativeVersion。

### 非目标

- 不用同一套模板同时覆盖图文、品牌广告和效果广告。
- 不在 MVP 阶段替代专业图像精修、调色和复杂非线性剪辑工具。
- 不将模型评分或历史高表现模式当作效果承诺。
- 不自动发布内容或上线广告；交付后由发布/投放流程执行。
- 不复制未经授权的竞品内容、人物形象、音乐或字体。

## 系统边界与模块导航

完整的 L0 至 L3 导航分布、路由与交互规则见 [四大模块导航与信息架构](./19-module-navigation-architecture.md)；子板块功能、必要性、价值和展示形式见 [四大模块子板块分析](./20-module-submodule-analysis.md)。本 PRD 维护业务职责。

### 系统边界

创意创作是独立垂直系统，路由前缀为 `/creative/*`。它拥有创意任务、方向、图文/视频内容、制作素材、版本、评审和交付包；共享基座只提供用户、Provider、知识、Codex/Skills、存储、任务和审计能力。

| 类型 | 内容 |
| --- | --- |
| 本系统拥有 | CreativeTask、CreativeDirection、CreativeDraft、EditTask、TimelineVersion、EditOperation、RenderJob、CreativeVersion、ProductionAsset、CreativePackage、CreativeReview |
| 从基座读取 | 用户组织、品牌知识、统一模型 Provider（LLM/VLM/图片/视频/音频/3D）、SkillDefinition、AgentTask、对象存储 |
| 从其他系统消费 | `strategy.approved.v1`、`insight.confirmed.v1` 及对应版本 API |
| 向其他系统发布 | `creative.approved.v1`、`creative.delivered.v1`、`creative.deactivated.v1` |
| 明确不拥有 | Brief、Strategy、AssetExperience、DeliveryPlan、平台效果事实 |

### Project 关联

- CreativeTask、EditTask、CreativeDirection、TimelineVersion、CreativeVersion、CreativePackage 和 CreativeReview 必须携带非空 `project_id`，并在页面标题区持续显示当前 Project。
- 从策略创建任务时默认只接受同一 Project 的批准 Strategy；交付包进入素材分析与投放时继续保留该 `project_id` 和来源版本链。
- 跨 Project 复用创意必须使用“复制到 Project”或授权引用，保留 `source_project_id`、原版本和权利范围；不得直接修改已批准对象的归属。
- 原始媒体文件可以是组织级共享资产，但 CreativeTask 中的使用关系、生成任务、评审和交付始终属于具体 Project。

### 创意任务内导航

进入一个 Creative Task 后，导航为：`概览 → 创意方向 → 内容编辑 → 制作素材 → 变体 → 检查 → 评审 → 交付 → 效果回流`。图文和视频在“内容编辑”后进入不同编辑器，但任务状态、版本和评审入口保持一致。

### 导航规则

- 图文和视频是平级主导航，不用筛选器隐藏在同一个通用编辑页面中。
- 视频创作内将“品牌广告制作”“效果广告制作”“素材剪辑”作为固定二级入口，分别记忆工作区状态；素材剪辑是通用工具，不作为第三种视频广告类型。
- “视频草稿”“视频版本”属于创作任务、剪辑任务和交付物的对象列表与详情，不与上述三个稳定工作区并列。
- 效果广告制作在三级导航提供“视频爆款复刻”“视频前贴”“AI 数字人”“AI 广告生成”，后续功能按同一注册机制扩展。
- Provider 配置、品牌知识和用户管理只链接到 `/admin/*`，创意系统不复制公共管理页面。
- “效果回流”只显示引用的素材洞察和投放结果，不在本系统创建分析结论。
- 导航权限使用 `creative.*` 动作，并支持文案、设计、剪辑、品牌审核等系统内角色。

## 3. 创意分类

### 3.1 分类树

| 一级形态 | 渠道 | 二级类型 | 主要目标 | 核心交付物 |
| --- | --- | --- | --- | --- |
| 图文 | 小红书 | 笔记/种草图文 | 兴趣、信任、收藏、互动、搜索承接 | 标题、正文、话题、封面、配图、发布建议 |
| 图文 | 公众号 | 文章/品牌内容 | 深度表达、品牌心智、私域承接 | 标题、摘要、头图、文章、内文配图、CTA |
| 视频 | 抖音/快手 | 品牌广告 | 认知、记忆、情绪、品牌资产 | 电影感故事、剧本、分镜、角色与场景、声音、品牌版成片 |
| 视频 | 抖音/快手 | 效果广告 | 点击、线索、下单、安装等效果转化 | 视频爆款复刻、视频前贴、AI 数字人、AI 广告生成及其多变体成片 |

素材剪辑不进入广告类型分类树。它可以处理品牌广告、效果广告或暂未分类的授权素材，但提交评审与交付前必须明确渠道、目标和最终 Creative 类型。

### 3.2 分类必填字段

每个 Creative 必须保存：

- `format`：`image_text` 或 `video`。
- `channel`：`xiaohongshu`、`wechat_official_account`、`douyin`、`kuaishou`。
- `video_purpose`：视频必填，`brand` 或 `performance`。
- `performance_mode`：效果广告必填，首期支持 `viral_remake`、`pre_roll`、`digital_human`、`ai_ad_generation`。
- `objective`：品牌或效果目标。
- `audience_segment`：目标人群。
- `strategy_version_id` 与 `asset_insight_ids`：策略和素材经验依据。

## 4. 用户与场景

| 角色 | 场景 | 成功标准 |
| --- | --- | --- |
| 内容运营 | 为新品生成一批小红书种草笔记 | 可直接评审，标题、正文、封面和配图表达一致 |
| 品牌编辑 | 把品牌故事写成公众号文章 | 结构完整、语气统一、事实与引用有来源 |
| 品牌创意 | 为抖音/快手制作电影感品牌故事 | 有完整故事、电影感视听、品牌记忆点和渠道适配 |
| 效果广告编导 | 使用视频爆款复刻、视频前贴、AI 数字人或 AI 广告生成生产效果广告 | 钩子、卖点、证明、CTA 变量清楚，可做实验 |
| 设计/剪辑 | 接手 AI 生成的内容初稿 | 素材、字幕、镜头、时长和版本关系明确 |
| 审核人 | 审查品牌、事实和合规 | 能按形态查看专属检查项，批准具体版本 |

## 5. 统一创作流程

1. 用户从已批准策略发起创意任务。
2. 选择一级形态、渠道；视频创意继续选择品牌广告制作或效果广告制作，效果广告还需选择具体功能；已有素材也可以直接创建独立 EditTask。
3. 系统加载对应渠道 Skill、品牌规范和素材经验。
4. Codex 生成 3—5 个有明确差异的创意方向，说明受众、洞察和适用场景。
5. 用户选择方向，生成完整图文内容包或视频创意包。
6. 系统执行形态专属的品牌、事实、渠道规格和合规检查。
7. 用户对话式修改或在编辑器中精修，锁定满意元素后生成受控变体。
8. 创意提交评审；批准版本进入素材分析并交给发布/投放模块。
9. 效果数据回流后，系统在创意详情展示表现与素材经验结论。

## 6. 图文创意要求

### 6.1 小红书图文

#### 交付内容

- 3—10 个标题候选及标题角度说明。
- 正文：开场、场景/痛点、体验/证明、产品价值、行动引导。
- 话题与关键词建议，区分品牌词、品类词、场景词。
- 封面文案、封面构图和图片生成/选材建议。
- 图组大纲：每张图的目的、画面、文案和顺序。
- 评论区互动建议、发布时间建议和风险提示。

#### 质量重点

- 表达自然、具体，不堆砌空泛营销术语。
- 种草体验、事实证明和商业信息边界清楚。
- 标题与正文承诺一致，不使用无法证明的夸张主张。
- 图组形成连续叙事，不只是同一主图的尺寸变化。

### 6.2 公众号图文

#### 交付内容

- 标题、备选标题、摘要和分享文案。
- 头图方向、文章大纲和完整正文。
- 章节标题、重点引用/数据、内文配图说明。
- 品牌信息、产品/活动 CTA、落地链接和必要声明。
- 公众号内容在手机画幅中的阅读节奏、排版建议与桌面工作台内预览。

#### 质量重点

- 逻辑完整，适合中长内容阅读。
- 品牌语气稳定，引用、数据和产品信息可追溯。
- 标题、摘要、头图和正文主张一致。
- CTA 与文章目标匹配，避免突兀硬转化。

## 7. 视频创意要求

### 7.1 共同交付结构

- 创意概念与一句话核心表达。
- 视频时长、比例、渠道、受众和目标。
- 脚本：画面、台词/口播、字幕、音效和转场。
- 分镜：镜头时长、景别、主体、动作、场景和所需素材。
- 封面、标题、发布/广告文案和 CTA。
- 素材清单：已有、需拍摄、需生成、音乐/字体/人物授权。
- 成片草稿及可编辑工程/清单（取决于接入的生成与剪辑能力）。

平台时长、文字、画幅和文件限制从版本化渠道规则读取，不在 PRD 中硬编码易变化参数。

### 7.2 品牌广告

#### 创作目标

生成具有电影感的品牌故事，建立品牌认知、情绪连接和记忆资产。评价重点是故事成立、品牌辨识、视听质感、情绪一致和记忆资产沉淀，而非只看短期点击。

#### 制作流程

品牌广告的操作顺序固定为：**解析 Brief → 编写剧本 → 生成资产 → 基于资产和剧本生成广告 → 剪辑与交付**。下列步骤是这五个阶段的细化，任何阶段都必须保留输入来源、人工确认和版本关系。

Strategy 来源是例外入口：Creative 应从已批准且冻结的 StrategyPackage、CreativeHandoff 与 brand_video Route 确定性投影自己的 Brand Brief，完成本地校验和一次显式接受后进入品牌方向，不再次调用模型解析同一批策略事实。手动上传 PDF、DOCX 或 Markdown 的品牌 Brief 仍保留解析、编辑与确认流程；素材权利与生产参数作为独立 readiness 门禁，不触发完整 Brief 重分析。

1. **故事设定**：从品牌策略、受众洞察和文化语境生成主题、世界观、情绪与一句话故事。
2. **故事提案**：产出 3 至 5 个有明显差异的 Logline、梗概、人物关系和品牌进入方式。
3. **电影剧本**：将选定故事发展为场景、动作、对白、节奏、情绪曲线和品牌记忆点。
4. **视觉开发**：确定影像风格、色彩、光线、构图、角色、服装、道具、场景和美术参考。
5. **分镜与镜头设计**：生成故事板、景别、机位、运动、时长、表演、转场和所需素材。
6. **角色与场景一致性**：建立角色、产品、场景和品牌资产参考，跨镜头保持身份与视觉连续性。
7. **镜头生成与制作**：逐镜头调用图片、视频、音频和 3D 能力，先生成低成本预演，再生成候选镜头。
8. **剪辑与声音**：完成镜头选择、节奏、音乐、对白、环境声、音效、字幕和品牌声音资产。
9. **调色与检查**：统一色彩和质感，执行故事、品牌、事实、授权、渠道和合规检查。
10. **评审与交付**：逐帧评审，批准不可变版本，并生成母版和渠道适配版本。

#### 核心工作区

| 工作区 | 主要内容 |
| --- | --- |
| 故事室 | 主题、Logline、梗概、人物、冲突、情绪曲线、品牌角色 |
| 剧本室 | 场景、动作、对白、节奏、时长和品牌记忆点 |
| 视觉开发 | 角色、场景、产品、美术、光线、色彩、服装和道具 |
| 分镜台 | 故事板、镜头、机位、运动、表演、转场和素材需求 |
| 制作台 | 参考锁定、逐镜头生成、候选比较、一致性和失败重试 |
| 后期台 | 剪辑、音乐、对白、音效、字幕、调色和母版输出 |

#### 专属检查

- Logo、品牌色、语气、产品露出和记忆资产是否一致。
- 故事是否在目标时长内完整，不因渠道适配破坏核心表达。
- 不因追逐前三秒钩子而损害品牌形象。
- 品牌主张和社会/文化表达是否存在风险。
- 角色、产品、服装、场景和光线在跨镜头生成中是否保持一致。
- 电影感是否服务故事和品牌，而不是堆叠慢镜头、宽银幕黑边或无意义运镜。

### 7.3 效果广告

#### 创作目标

在清晰转化目标下，通过功能化创作流程快速生产并验证表达。评价重点是钩子、痛点、卖点、证据、CTA、可测试性和单位产出效率。

效果广告首期只能从以下四种生成类型中选择其一；各类型共享策略、渠道规格、品牌规则、来源授权、版本、检查与交付契约，但有独立的输入、生产流程与专属风险检查。

1. **视频爆款复刻**：拆解获授权参考视频的结构和节奏，完成品牌映射与原创改写。
2. **视频前贴**：为原视频生成并拼接 4–10 秒的高注意力开场。
3. **AI 数字人**：使用已授权的数字人形象与声音完成口播广告。
4. **AI 广告生成**：基于转化目标、卖点和品牌规则，端到端生成整条广告。

#### 功能一：数字人

- 输入：商品与活动信息、受众、口播目标、脚本或卖点、数字人授权、声音授权和渠道规格。
- 流程：生成口播脚本 → 选择数字人和声音 → 配置场景与商品演示 → 生成口型与动作 → 添加字幕、贴片和 CTA → 生成变体 → 检查与交付。
- 编辑能力：台词分段、情绪、语速、停顿、手势、视线、景别、背景、商品图层、字幕与贴片。
- 强制检查：数字人和声音授权、AI 标识、口型同步、人物异常、事实与行业合规。

#### 功能二：广告前贴

- 定义：用于内容播放前或视频开头的短时长效果广告，快速完成受众识别、核心利益表达和行动引导。
- 输入：转化目标、核心卖点、优惠或机制、证明素材、CTA、目标时长和渠道规格。
- 流程：选择前贴结构 → 生成开场钩子 → 编排卖点与证明 → 设计产品画面和文字贴片 → 生成声音与字幕 → 创建时长和 CTA 变体 → 检查与交付。
- 模板类型：痛点直入、结果先行、反差、问题、强利益、场景触发和商品演示。
- 强制检查：首帧可读性、信息密度、静音可理解性、优惠条件、必要声明和落地页一致性。

#### 功能三：爆款视频复刻

- 定义：复用参考视频中可解释的内容结构与节奏，不复制未经授权的画面、人物、音乐、台词或品牌资产。
- 输入：参考视频或链接、目标产品、目标受众、品牌规范、转化目标和允许复用的自有素材。
- 流程：导入参考 → 拆解钩子、结构、节奏、镜头和 CTA → 标记可复用机制与不可复制元素 → 映射品牌和产品 → 重写脚本与分镜 → 生成原创素材 → 创建变体 → 原创度、授权与合规检查 → 交付。
- 对比视图：参考结构、改写结构、逐段映射、相似性风险、素材来源和修改依据。
- 强制检查：版权、肖像、音乐、商标、台词相似性、平台搬运规则和品牌一致性。

#### 功能四：AI 广告生成

- 定义：不依赖既有成片或单一模板，基于转化目标、产品卖点、受众洞察、品牌规则和可用资产，端到端生成完整效果广告。
- 输入：转化目标、产品/活动信息、受众、核心卖点、证据、CTA、渠道规格、品牌规则与可用资产。
- 流程：效果脚本与变量矩阵 → 分镜 → 视觉、音频与字幕资产生成 → 候选广告生成 → 多轨剪辑与渠道适配 → 检查、评审与交付。
- 强制检查：事实与优惠条件、品牌一致性、资产来源与权利、AI 披露、渠道规则、成本和失败重试。

#### 通用效果广告结构

1. 开场钩子：问题、结果、反差、场景或强利益点。
2. 痛点与受众识别。
3. 产品机制、核心卖点和使用演示。
4. 证明：体验、数据、口碑、前后对比或权威信息。
5. CTA、优惠或稀缺信息与必要声明。

#### 变体原则

- 默认围绕钩子、受众、卖点、证明、CTA、人物/场景分别建立变量。
- A/B 对照尽量一次只改变一个主要变量。
- 每个变体记录假设和期望影响，不只记录文件差异。
- 快速产量不能绕过事实、授权和合规检查。
- 每个成片保存 `performance_mode`，并记录使用模板、参考内容、数字人、声音和素材授权。

### 7.4 素材剪辑

素材剪辑是视频创作中的独立通用工作区，不改变品牌广告或效果广告分类。用户可以从品牌/效果任务携带素材进入，也可以直接使用上传素材、项目素材和 AI 生成镜头创建 EditTask。

#### 功能范围

- 素材箱：上传、项目素材、生成镜头、图片、配音、音乐、音效及授权状态。
- 多轨时间线：移动、裁切、分割、删除、吸附、间隙、缩放、波形、撤销与重做。
- 画面：预览、比例、裁切、缩放、位置、背景、安全区和封面帧。
- 字幕与文字：自动字幕、人工校对、品牌样式、关键词强调和烧录。
- 音频：原声、配音、音乐、音效、音量、静音和淡入淡出。
- 版本与导出：自动保存、TimelineVersion、低清预览、母版、渠道版本和 RenderJob。
- P1 AI 辅助：删除停顿、精彩片段、节奏建议、横竖版重构和批量广告变体。

编辑器采用“左侧素材箱 + 中央预览 + 右侧属性检查器 + 底部多轨时间线”的单一工作区，不把字幕、音频、转场继续拆成新的导航层。详细产品和开源架构见 [视频素材剪辑与开源框架方案](./21-video-material-editor-spec.md)。

## 10. 编辑、评审与状态

### 10.1 工作台

- 左侧：形态/渠道、策略摘要、创意方向和版本树。
- 中间：图文编辑器或视频脚本/分镜时间线与预览。
- 右侧：品牌规范、素材经验、检查结果、Skill 记录和评论。
- 底部：候选与变体对比，显示本次改变的变量。

### 10.2 状态

`草稿 → 生成中 → 待检查 → 待评审 → 已批准 → 已交付 → 已停用`

- 严重检查项存在时不能提交或批准。
- 已批准版本不可修改；改动创建新版本并重新评审。
- 已交付版本停用时保留投放与分析历史。

### 10.3 评分

共同维度：策略匹配、品牌一致、事实可靠、渠道适配、合规风险。

- 小红书：标题/正文一致、真实感、图组叙事、互动潜力。
- 公众号：结构、信息深度、阅读节奏、品牌表达、CTA 衔接。
- 品牌广告：故事、电影感、品牌辨识、叙事、情绪、记忆资产和制作完成度。
- 效果广告：钩子、卖点、证明、CTA、可测试性和信息效率；数字人、前贴和复刻分别增加专属检查。

评分用于提示问题，不作为投放效果预测。

## 12. 指标与埋点

### 12.1 通用指标

- 策略批准到首批可评审创意的中位时长。
- 每种形态的方向采用率、首轮通过率、平均修改轮次和交付率。
- Skill/生成任务成功率、P95 时延和单个采用创意成本。
- 事实、品牌、版权和合规问题检出率。

### 12.2 分类指标

- 小红书：发布率、阅读/曝光、互动、收藏、搜索或转化指标（按业务数据可用性）。
- 公众号：打开、阅读完成、分享、关注或 CTA 转化。
- 品牌广告：播放完成、互动、品牌搜索或认知等可获得指标。
- 效果广告：按数字人、广告前贴、爆款视频复刻分别统计点击、转化、CPA、CVR、ROAS、素材衰减和变体胜出率。

指标展示必须包含渠道、目标、受众、投放环境、时间和样本提示。

## 13. 非功能要求

- 文本编辑操作 P95 小于 300ms；图像、视频生成与渲染采用异步任务。
- 视频任务支持排队、取消、逐镜头重试和部分结果保留。
- 原始上传和已批准版本不被生成任务覆盖。
- 每种形态使用独立 Schema，禁止把缺失字段静默填成无意义默认值。
- 批量生成前展示候选数量、预计耗时和成本，并受组织配额限制。
- 预览与最终交付在字幕、时序、裁剪、字体和音轨上保持可验证一致。
- 上传、生成、转码、预览、Asset ID/Version、权利元数据和删除遵循 [媒体资产平台](./11-media-asset-platform.md)。
- AI 标识、页面状态、并发编辑和需求追踪遵循 [PRD 通用交互与质量要求](./15-prd-cross-cutting-requirements.md)。

## 14. MVP 验收标准

1. 创建 CreativeTask 时必须明确图文/视频和渠道；视频创意未选择品牌广告制作或效果广告制作不能继续，效果广告未选择具体功能不能继续；独立 EditTask 可从素材开始，但提交评审前必须绑定最终 Creative 类型。
2. 小红书任务能交付标题、正文、话题、封面和连续图组方案。
3. 公众号任务能交付标题、摘要、头图、大纲、完整正文、配图和 CTA。
4. 品牌广告任务能从故事提案进入剧本、视觉开发、分镜、角色场景、镜头生成、剪辑声音和成片草稿，并保持跨镜头一致性。
5. 数字人效果广告能交付已授权数字人和声音的口播成片，并通过口型、人物异常、AI 标识和合规检查。
6. 广告前贴能按目标时长交付至少 3 个钩子变体，并验证静音可理解性、优惠条件与落地页一致性。
7. 爆款视频复刻能展示参考结构与改写结构的映射，禁止复用未经授权素材，并通过相似性与版权检查。
8. 抖音与快手任务调用对应渠道 Skill，输出中能查看 Skill 版本。
9. 锁定品牌 Logo、主张、角色或指定镜头后重生成，其内容保持不变。
10. 视频部分镜头生成失败时保留成功镜头，只重试失败部分。
11. 严重事实、授权、相似性或合规问题未解决时不能批准和交付。
12. 审核批准具体不可变版本；修改后必须重新评审。
13. 交付包包含内容、参考与素材来源、授权状态、版本、渠道规则和检查结果。
14. 投放效果回流后，能按图文、品牌广告、数字人、广告前贴和爆款视频复刻分别进入素材分析。
15. `/creative/*` 独立提供图文、视频、制作、评审和交付导航；素材洞察或投放系统不可用时仍能完成创意草稿工作。
16. 用户可独立创建素材剪辑任务，完成多轨裁切、字幕、音频、比例适配、版本保存、低清预览和异步导出。
17. 预览与最终成片在时序、裁切、字幕、字体和音轨上通过固定样例一致性验证。
18. OpenCut 候选框架和 FFmpeg 渲染链路必须通过许可证、固定版本、性能、隔离和退出方案评审。

## 15. 依赖与风险

| 风险 | 缓解措施 |
| --- | --- |
| 四类内容被同一模板同质化 | 形态/渠道/目标独立 Skills、独立 Schema 和评测集 |
| 图文只生成文案不形成内容包 | 强制封面、配图/图组、排版和发布信息验收 |
| 品牌广告被效果逻辑侵蚀 | 独立故事、电影感、评分和审批标准，不以短期点击单一评价 |
| 效果广告批量低质或违规 | 功能专属 Schema、受控变量、证据绑定、配额、合规阻断和人审 |
| 爆款复刻侵犯版权或形成搬运 | 只复用可解释结构，强制原创改写、素材授权、相似性检查和人工审核 |
| 数字人出现授权或人物异常 | 数字人和声音许可、AI 标识、口型与肢体异常检测、逐版本审查 |
| 视频生成成本和失败率高 | 分镜先确认、低清预览、逐镜头生成、缓存和失败重试 |
| 平台规则变化 | 渠道规则版本化，Skills 独立升级与回滚 |
| 历史经验造成路径依赖 | 经验显示适用条件，同时保留探索配额和新方向 |
| 开源编辑器快速演进或导出不稳定 | 固定 release/commit、隔离适配层、建立渲染一致性用例，并保留自有时间线 Schema 与替换能力 |
| 浏览器预览与最终导出不一致 | 同一 TimelineVersion 驱动预览和 FFmpeg Render Worker，使用固定素材做逐帧与音轨回归 |

## 16. 待确认项

1. OpenCut 技术验证后采用组件、维护 fork 还是仅参考交互；FFmpeg 的部署与许可证编译策略。
2. 小红书、公众号是否需要直接发布；本稿默认只生成发布包。
3. 品牌广告与效果广告是否需要不同审批角色；本稿建议品牌负责人和效果投放负责人分别审批。
4. 首期渠道规则、版权音乐、字体和人物授权来源。
5. 抖音/快手各自的首批行业模板和评测样例。
